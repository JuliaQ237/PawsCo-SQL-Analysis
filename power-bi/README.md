# PawsCo Power BI Analysis

This folder contains the interactive Power BI report developed for the PawsCo sales and budget analysis project.

## Report Pages

### Overview

Provides an executive summary of:

- Revenue performance
- Year-over-year growth
- Actual versus budget performance
- Monthly revenue trends
- Sales-channel performance
- Store-level filtering

### Product Analysis

Examines product performance through:

- Top-five products by revenue
- Gross-margin decomposition
- Product-category analysis
- Customer pet-type analysis
- Report-page tooltips
- Category-level drillthrough

### Budget Analysis

Compares actual revenue against budget by:

- Product category
- Store and country
- Quarter and month
- Selected business dimension

The page also shows progress toward the annual budget goal.

## Reporting Period

The dataset contains transactions through 21 October 2026.

YTD KPI comparisons use the latest completed reporting month, ending 30 September 2026. October remains available in monthly trend visuals as a partial month.

## Interactive Features

- Dynamic field parameters
- Drillthrough analysis
- Report-page tooltips
- Decomposition tree
- Conditional formatting
- Quarter and month filtering
- Reset and page-navigation buttons

## Power BI File

Download [Power BI report](PawsCo_Analysis.pbix) to explore the interactive report.

> The report uses a local SQL Server data source. After downloading the PBIX file, users may need to update the data-source connection before refreshing the model.
